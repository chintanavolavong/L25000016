一、项目功能

本项目把第6周的双引擎问答功能和第7周的 RAG 知识库问答功能结合起来，制作一个国际中文教学助手。

助手主要面向 HSK3—4 学习者，可以回答中文语法、词汇和课堂教学方面的问题。

二、RAG 功能对应关系

功能	对应代码	作用
环境配置	weekpath.load_env()	加载环境变量
双引擎调用	from llm import LLM	调用本地或云端模型
知识检索	retrieve(question)	根据问题检索相关资料
提示词构建	build_prompt(question, ctx)	把问题和参考资料组合起来
RAG 模式	use_rag=True	使用检索资料辅助回答
普通模式	use_rag=False	不使用检索资料，直接回答
模型选择	prefer="local"	优先使用本地模型

三、程序运行流程

用户输入问题后，程序先判断是否使用 RAG。

如果 use_rag=True，程序调用 retrieve(question) 获取参考资料，再通过 build_prompt() 生成提示词，最后调用语言模型回答。

如果 use_rag=False，程序直接把问题发送给语言模型。

程序通过 llm.ask() 完成模型调用。

四、测试情况

本次使用了三个问题：

1. 把字句的教学难点有哪些？
2. HSK4 词汇量要求是多少？
3. 《愚公移山》可以设计什么课堂活动？

在 assistant_v1.py 的测试部分，设置了 use_rag=False 和 prefer="local"。

因此，这三个测试主要展示普通问答模式的输出结果，不能直接代表 RAG 检索模式的效果。

详细回答记录见 answer_log.md。

五、已知限制

1. 本地模型需要正确安装并启动 Ollama。
2. RAG 功能依赖第7周的知识库检索模块。
3. 如果缺少相关文件或依赖，程序可能无法正常运行。
4. AI 生成的回答可能存在错误，需要人工检查。

六、总结

通过第8周的作业，我学习了如何把双引擎和 RAG 功能组合在一个程序中。

这个项目可以使用普通问答模式，也提供了基于知识库的问答接口。

以后我希望进一步测试 RAG 模式，提高回答的准确性。
